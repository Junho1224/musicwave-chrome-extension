# Music Wave Alert

멜론 MUSIC WAVE의 확인·감지 팝업을 찾아 PC와 휴대폰으로 알려주는 Chrome 확장 프로그램입니다.

## 다운로드

**[Music Wave Alert v1.1.1 다운로드](./release/music-wave-alert-extension-v1.1.1.zip?download=1)**

ZIP 파일을 받은 뒤 압축을 풀고 아래 순서대로 설치하세요.

## 1. Chrome에 설치하기

현재 버전은 Chrome 웹 스토어에 등록되지 않았으므로 개발자 모드로 설치합니다.

1. 다운로드한 ZIP 파일의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. `manifest.json` 파일이 들어 있는 폴더를 선택합니다.
6. Chrome 확장 프로그램 목록에 **Music Wave Alert 1.1.1**이 나타나는지 확인합니다.

설치 후 Chrome 오른쪽 위의 확장 프로그램 메뉴에서 Music Wave Alert를 고정해두면 편리합니다.

## 2. 처음 설정하기

1. 멜론 MUSIC WAVE 페이지를 엽니다.
2. 설치한 **Music Wave Alert** 아이콘을 누릅니다.
3. 상단에 **현재 탭을 감시하고 있습니다**가 표시되는지 확인합니다.
4. **PC 테스트 알림 보내기**를 눌러 PC 알림이 오는지 확인합니다.
5. 원하는 알림 설정을 켭니다.
6. 이미 열려 있던 MUSIC WAVE 페이지라면 한 번 새로고침합니다.

### 알림 설정

| 설정 | 기능 |
| --- | --- |
| 데스크톱 알림 | Windows와 Chrome 알림으로 알려줍니다. |
| 페이지 경고음 | MUSIC WAVE 탭에서 경고음을 재생합니다. |
| 탭 제목 깜빡임 | 다른 탭을 보고 있을 때 탭 제목을 깜빡입니다. |
| 휴대폰 알림 | ntfy 앱 또는 웹 푸시로 휴대폰에 알려줍니다. |

## 3. 평소 사용 방법

Chrome과 MUSIC WAVE 탭을 열어두면 확장 프로그램이 자동으로 감시합니다. Codex와 휴대폰 연결 안내 페이지는 계속 켜둘 필요가 없습니다.

| 감지 내용 | 알림을 받은 뒤 할 일 |
| --- | --- |
| 계속 들으시겠습니까? | PC 알림의 **이 탭 새로고침**을 누르거나 MUSIC WAVE 탭에서 직접 확인합니다. |
| 기계적인 스트리밍 패턴 감지 | 알림을 눌러 MUSIC WAVE 탭으로 이동한 뒤 직접 인증합니다. |

팝업 확인이나 인증은 자동으로 처리되지 않습니다. 휴대폰 알림을 받으면 PC의 MUSIC WAVE 탭을 확인해주세요.

## 4. 휴대폰 알림 연결하기

휴대폰 알림은 **ntfy 앱으로 받기**와 **앱 없이 웹으로 받기** 중 편한 방법을 선택할 수 있습니다.

연결 안내 페이지: <https://music-wave-alert-connect.ho1.chatgpt.site>

### 연결 시작

1. PC에서 Music Wave Alert 아이콘을 누릅니다.
2. **휴대폰 알림**을 켭니다.
3. **휴대폰 연결 만들기**를 누릅니다.
4. 화면에 표시된 QR 코드를 휴대폰 카메라로 스캔합니다.
5. 휴대폰에서 원하는 알림 방식을 선택합니다.

### 방법 A: ntfy 앱으로 받기

알림을 안정적으로 받고 싶다면 앱 방식을 권장합니다.

1. 연결 페이지에서 **ntfy 앱으로 받기**를 선택합니다.
2. 휴대폰에 ntfy 앱이 없다면 안내에 따라 설치합니다.
3. ntfy 앱에서 연결된 알림 주제를 구독합니다.
4. 휴대폰의 알림 권한을 허용합니다.
5. PC의 Music Wave Alert로 돌아와 **휴대폰 테스트**를 누릅니다.

### 방법 B: 앱 없이 웹으로 받기

1. 연결 페이지에서 **앱 없이 웹으로 받기**를 선택합니다.
2. ntfy 웹페이지에서 해당 알림 주제를 구독합니다.
3. 브라우저 알림과 백그라운드 알림을 허용합니다.
4. PC의 Music Wave Alert로 돌아와 **휴대폰 테스트**를 누릅니다.

Android에서는 ntfy 웹페이지를 홈 화면에 추가하면 편리합니다. iPhone은 iOS 16.4 이상에서 Safari로 페이지를 열고 **홈 화면에 추가**한 뒤 알림을 허용해야 웹 알림을 받을 수 있습니다.

테스트 알림이 정상적으로 도착하면 연결 안내 페이지는 닫아도 됩니다. QR 코드로 연결한 주소에는 개인 알림 채널 정보가 포함되어 있으므로 다른 사람에게 공유하지 마세요.

## 알림이 오지 않을 때

### PC 알림이 오지 않는 경우

- 확장 프로그램에서 **PC 테스트 알림 보내기**를 다시 눌러봅니다.
- Windows 설정에서 Chrome 알림이 허용되어 있는지 확인합니다.
- `chrome://extensions`에서 Music Wave Alert가 켜져 있는지 확인합니다.
- MUSIC WAVE 페이지를 새로고침한 뒤 확장 프로그램 상단의 감시 상태를 확인합니다.

### 휴대폰 알림이 오지 않는 경우

- 확장 프로그램에서 **휴대폰 알림**이 켜져 있는지 확인합니다.
- **휴대폰 테스트**를 눌러 연결 상태를 확인합니다.
- 휴대폰에서 ntfy 앱 또는 브라우저의 알림 권한을 확인합니다.
- 웹 방식이라면 ntfy 알림 주제가 구독된 상태인지 확인합니다.
- iPhone 웹 방식이라면 Safari 페이지가 홈 화면에 추가되어 있는지 확인합니다.

### 경고음이 들리지 않는 경우

- Music Wave Alert의 **페이지 경고음** 설정을 확인합니다.
- MUSIC WAVE 탭이나 Chrome이 음소거되어 있지 않은지 확인합니다.

## 선택 팁: 탭별 볼륨 조절

[Volume Master](https://chromewebstore.google.com/detail/volume-master/jghecgabfgfdldnmbfkhmffcabddioke)를 사용하면 Chrome 탭마다 볼륨을 0%부터 600%까지 조절할 수 있습니다.

MUSIC WAVE 탭을 음소거하면 페이지 경고음도 들리지 않을 수 있으므로 PC 알림 또는 휴대폰 알림을 함께 켜두세요.

## 기억해둘 점

- Chrome과 MUSIC WAVE 탭이 종료되면 팝업을 감지할 수 없습니다.
- Chrome·Windows·휴대폰의 알림 권한이 꺼져 있으면 시스템 알림이 표시되지 않습니다.
- 사이트 화면이나 팝업 문구가 변경되면 감지가 동작하지 않을 수 있습니다.
- 계속 듣기 새로고침은 사용자가 PC 알림의 버튼을 눌렀을 때만 실행됩니다.
- 기계적 스트리밍 인증은 사용자가 MUSIC WAVE 탭에서 직접 진행해야 합니다.
